📖 Usage Guide

Running an Analysis

  1. Navigate to Coverage Analysis or Repository Understanding
  2. Enter your repository paths (local folder or remote Git URL)
  3. Click "Start Analysis"
  4. Wait for analysis to complete (progress is shown in real-time)
  5. View the report in your browser or export as HTML/JSON

Supported Repository Types

  • Local folder paths (absolute path)
  • Remote Git repositories (HTTPS or SSH URL)
  • GitHub repositories (https://github.com/owner/repo)

Supported Languages

Java, Kotlin, TypeScript, JavaScript, Python, Ruby, Go, C# — and more via generic file analysis.
